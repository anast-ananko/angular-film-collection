## 📖 About

A simple Angular application for browsing films, searching, and managing favorites.

---

## ✨ Features

- 🎞 Film list with posters and details
- 🔍 Search films by title
- ⭐ Add/remove favorites
- 📄 Film details page
- 💾 Local JSON data (no backend)
- ⚡ Fast and responsive UI

---

## 🛠 Tech Stack

- Angular
- TypeScript
- Angular Signals
- SCSS

---

## 🚀 Run project

```bash
npm install
ng serve
```
